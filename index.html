NKUMA SUPPORT

nkuma の使い方と環境管理の正本。

nkuma は、Claude Code の上で動く南国ソフトの AI 業務アプリ基盤です。
専門家 skill たちと対話しながら、顧客理解 → 設計 → 実装 → 公開まで一本の道で進めます。

勉強会 — はじめての一本を作る

これから勉強会に参加する人向け。
nkuma で何が作れるのか、当日までの準備、当日の道のり。
まずここから読んでください。

勉強会ページへ → nkuma を使う

これから使い始める人・使っている人向け。
初回セットアップ (ターミナル)、日常利用 (Claude アプリ)、最初の一歩、困った時の手引き。

利用者ガイドへ → nkuma を更新する

管理者から「新しい版を配布しました」の案内が来たら。
plugin とテンプレートの更新手順。

更新ガイドへ → nkuma 環境を管理する

環境管理者向け。
環境の整備 (bicep / 手動構築)、メンバー招待、リポジトリ登録、最新版へのアップデート。

管理者ハンドブックへ →
はじめての人へ: 勉強会に参加する人は勉強会ページから、それ以外の人は利用者ガイドの「1. 全体像」から始めてください。
使う道具は 2 つだけ — 初回セットアップはターミナル、日常の利用は Claude アプリ (デスクトップ版) です。
管理者 (taiga) への依頼 1 つと、ツールの準備だけで使い始められます。
