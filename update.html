UPDATE GUIDE

nkuma を最新にする。

nkuma の更新は自動では届きません。
管理者から「新しい版を配布しました」の案内が来たら、このページの手順で受け取ります。
やることは 2 つだけ、あわせて 5 分ほどです。

対象: nkuma を使っているすべての人 — 管理者からの案内が来た時に
お知らせ 1. 更新のきほん 2. plugin のアップデート 3. テンプレートのアップデート 4. 困った時
NEWS

お知らせ — アプリの検査が強化されました (2026 年 8 月)

今回の配布から、nkuma で作るアプリに「書いたコードを機械が検査する仕組み」が標準で入ります。
コードの書き方の検査 (lint) と型チェックが保存のたびに自動で走り、変更を取り込む前には AI の独立レビュー、公開の前には実画面テストが必ず行われるようになります。
品質のチェックが「人が思い出したらやる」ではなく、いつも自動でかかる状態になる — という更新です。

受け取り方はいつもどおり 2 つ、この順で行ってください:

  1. §2 plugin のアップデート (PC ごとに 1 回)。
  2. §3 テンプレートのアップデート (開発中の案件ごとに 1 回)。
    今回は部品の差し替えに加えて「接続の調整」も提案されます — 内容を見て OK すれば nkuma が適用します。
    公開の仕組みだけ使っている案件や、いま動かしていない案件は急がなくて大丈夫です。
テンプレート更新後、これまでのコードに「赤」(検査エラー) が出ることがあります。
壊れたのではありません — これまで見えていなかった注意点が、見えるようになっただけです。
Claude アプリで「検査のエラーを直して」と頼めば、nkuma がコードを直してくれます。
急ぎの用がなければ、次の開発のついでに直せば十分です。
OVERVIEW

1. 更新のきほん — 何を・どこで・何回

更新するものは 2 つあります。
役割と回数が違うので、先に全体を掴んでください:

何を中身どこでやる回数
plugin (§2)nkuma の専門家 skill 群 — 対話の頭脳ターミナルPC ごとに 1 回 (全案件に効く)
テンプレート (§3)案件リポジトリに同梱された仕組みの部品 (CI 設定・公開ガイドなど)Claude アプリ (案件を開いて)案件ごとに 1 回
エンジン (データ保存の土台) の更新はここに含まれません。
手元のエンジンは、アプリを動かす時に AI が最新版と照合して「更新するか今のままか」を訊いてくれます — 選ぶだけで OK です。
ただし照合には GitHub への接続が要ります — つながらない時は照合を飛ばして今の版のまま起動するので、その回は更新の案内が出ません。
公開済みアプリのエンジン更新は管理者の作業です (あなたの操作はありません)。
STEP 1 — PLUGIN

2. plugin のアップデート (ターミナルで 2 コマンド)

使っている PC で 1 回だけ実行します。
どのフォルダにいても OK、Claude Code の画面を開く必要もありません。

1
ターミナルを開いて 2 コマンドを実行する
1 つずつ貼り付けて Enter (開き方を忘れたら利用者ガイド 2.3):
claude plugin marketplace update nkuma-marketplace
claude plugin update nkuma@nkuma-marketplace
2
新しい版になったか確認する
claude plugin list
nkuma@nkuma-marketplace の Version が、案内された版 (例: v20260801-1) になっていれば OK です。
3
Claude アプリのセッションを開き直す
開きっぱなしのセッションは古い版のまま動きます。
新しいセッションを始めれば、そこから新版です。
Claude アプリの中で /plugin ... と打っても動きません (アプリの仕様)。
plugin の操作は必ずターミナルで行います。
STEP 2 — TEMPLATE

3. テンプレートのアップデート (案件ごとに、アプリで頼む)

テンプレートは、案件リポジトリに同梱されている「仕組みの部品」(CI 設定・公開ガイド DEPLOY.md など) です。
こちらは案件の中身に関わるので、案件ごとに Claude アプリの中で更新します。

1
案件フォルダを Claude アプリで開く
いつもどおり、更新したい案件のフォルダでセッションを始めます。
2
「テンプレートの更新を適用して」と頼む
チャット欄に /nkuma:nk-template-update と入力しても同じです。
nkuma が最新版と照合して、変わる部分の差分を見せてくれます。
3
差分を見て、適用を決める
適用するかはあなたの確認を経てからです。
迷ったら nkuma に「この差分はどういう意味?」と聞けば説明してくれます。
あなたが書いたアプリのコードには触れません。
更新が扱うのは nkuma が同梱した部品だけで、扱いは 2 種類あります: 仕組みの部品 (CI 設定など) はあなたの confirm を経て適用され、見本コード (管理画面など) は「差分のお知らせ」だけが届きます。
お知らせが来ても適用は自由です — 自分で書き換えた部分を勝手に戻したりはしません。
また、テンプレート更新はいつも必要なわけではありません — 管理者のアナウンスに「テンプレも更新してください」とある時だけで大丈夫です。
TROUBLESHOOTING

4. 困った時

症状対処
更新したのに skill の挙動が変わらないClaude アプリのセッションを開き直したか確認 (§2 の手順 3)。
直らなければ claude plugin uninstall nkuma@nkuma-marketplace → 利用者ガイド 2.7 で入れ直し (何度やっても安全)
claude plugin update がエラーになるgh auth status でログイン確認 (利用者ガイド 2.5)。
初回導入がまだなら利用者ガイド 2.7 へ
その他利用者ガイドの「困った時の手引き」へ。
解決しなければ管理者 (taiga) に聞いてください
